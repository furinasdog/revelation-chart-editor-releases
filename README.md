# 更好的制谱器 Hub

Windows x64 版本管理器。下载安装 Hub 后，可在「版本库」安装和启动制谱器。Hub 支持签名更新和离线启动。[下载 Hub v1.6.1](https://github.com/furinasdog/revelation-chart-editor-releases/releases/download/hub-v1.6.1/Revelation-Hub-v1.6.1-x64.msi) · [Hub 源码与构建说明](更好的制谱器Hub/README.md)

## 制谱器 v1.5.0 正式版

工作区、键设置和吸附已更新，事件类型可以恢复到默认状态。Agent 和自动采音默认隐藏，使用原机器码可向原作者申请 RSA-4096 解锁码。[正式版发行页](https://github.com/furinasdog/revelation-chart-editor-releases/releases/tag/v1.5.0)

## 源码与许可

公开部分包括 Hub、原创桌面功能、制谱 Agent、MCP、命令行、节奏扩展与相关测试。自有代码采用 GPL-3.0-only。编辑器二进制包含上游制谱器的改进版本，使用 GDSO 混淆和 PCK 加密。公开源码树限于可单独开放的部分，完整编辑器的构建还需要独立获授权的上游工程和素材。[GPL 全文](LICENSE) · [第三方声明](THIRD_PARTY.md)

提交问题时请附 Windows 版本、软件版本、复现步骤及预期结果。可分享最小测试谱面。请先移除 API Key、本机路径和私有音乐素材。
