# 更好的制谱器 v1.1.0 新手教程

第一次用，可以从一份已有的谱面压缩包开始练习。下面用一首歌带你完成导入、放键、移动、预览和导出。

软件首次启动时会询问使用经历，再让你预览主题和选择快捷键。「第一次制谱」会打开实操引导，「用过原版制谱器」会介绍新版入口和当前键位，「用过这个分支」会直接进入工作区。可从「帮助」重开首次设置、首次制谱教程或原版迁移引导。

找不到功能时，点右下「功能速查」搜索，例如「歌词」「波形」或「自动吸附」，选中结果后点「前往此处」。左上「全部页签」可以直接打开任意检查器页。

## 1. 导入歌曲或谱面

空卷帘中央提供「从音频开始制谱」和「打开已有谱面」。两项也可以从左上「文件」菜单打开。可以把歌曲、谱面、歌词和图片直接拖入窗口。

| 手里有什么 | 选哪个入口 |
| --- | --- |
| 一整份已有谱面（ZIP） | 选「打开已有谱面」。编辑器会读取压缩包内的谱面和资源。 |
| 单独的谱面文件（JSON） | 选「打开已有谱面」。把歌曲和图片与谱面文件放在同一资源目录，保持原来的文件名。 |
| 只有歌曲，准备从头制谱 | **文件 → 导入音频**，选 MP3、WAV 或 OGG。弹窗可按当前设置自动分析，也可调整分析项目或暂不分析。 |
| 歌词和背景 | **文件 → 导入歌词**生成底部文字，**文件 → 导入背景图片**设置默认背景。只导入音频时，同名 LRC 默认保留在原处，可从偏好设置的「音频」页开启同名导入。 |

导入后，顶部菜单右侧显示歌曲名和当前谱面时间。想看速度曲线，可以点右上「节奏分析」。想编辑音符，视线回到底部网格。

## 2. 在底部卷帘放下第一个音符

1. 找到**底部网格上沿**的画笔栏，点「普通键」，随后在网格空白处单击。也可切换到「滑键」工具。
2. 放长键时，在**同一行**依次点击起点和终点。放好后可拖动两端调整时长，拖动黄色判定三角调整判定时刻。
3. 用「选择」工具单击音符，左上「键设置」会显示它的时间和位置。标准方案用左键框选，按住上档键可追加。原版方案按住上档键用右键框选。

**试放一个黄键（滑键）。** 选「滑键」，在下一拍单击空轨，点击处决定收圈判定的时间。点预览上方「添加滑动路径」，拖动起点或终点。从键出现前播放，观察它在终点收圈。也可以先定位播放头，打开「在画面放键」，直接点预览中的目标位置。

## 3. 改时间、改位置、做动画

| 想改什么 | 怎么操作 |
| --- | --- |
| 音符出现在哪一拍或哪一轨 | 标准方案用「选择」工具左键拖动音符主体。原版方案按住控制键用左键拖动。横向改变时间，纵向改变轨道。 |
| 音符在游戏画面里的位置 | 在停止播放的编辑状态下，到右上预览区拖动音符。原版方案拖动时按住控制键。打开「位置吸附」后会对齐预览网格。 |
| 让音符沿一条路径移动 | 选中音符，在左上「键设置」勾选「启用移动」。先试「直线」并输入终点坐标。切到「圆弧」后再设置弧线中点。在「缓动」里可调整这一段移动的速度变化。 |
| 让一条路径分成多段 | 在「多段移动（关键帧时间轴）」的刻度带上单击插入关键帧，拖动菱形调整它的时刻。选中要修改的段，再填写终点、中点或缓动。 |

参数栏太窄时，可拖动检查器与预览区之间的分隔线来加宽检查器。

要做遮罩动画，点卷帘画笔栏的「背景与遮罩」，定位到需要变化的拍子，先试「压暗背景」，再到下一处点「添加圆形揭示」。单击背景轨上的片段，点「循环预览此段」检查底图、遮罩和音符叠加的效果。

卷帘工具栏的「参考模式」可以切换三种参考线，也可在旁边控制「时间吸附」和金色拍点的显示。

- **传统量化**适合已知 BPM 的歌曲。在检查器「参考线量化」设置速度、拍内细分和变速节点。
- **自动速度**适合需要估计速度或跟随变速的歌曲。「自动抓音」分析拍点与速度后，蓝线按速度曲线标出整拍，每拍细分四格。
- **抓取拍点**适合直接对准实录鼓声。在「自动抓音」映射拍点、起音或力度重音，时间吸附只使用金色标记。前两种模式也可以叠加显示金色标记。

使用 Co-pilot 时可以直接引用标尺。比如在 120 BPM、从零开始的谱面上，第 25 拍下方的 `0:12.0` 就是 12 秒。可以说「把 12 秒的普通键往左移，保留长键」。选中音符后，检查器也会显示它的编号、拍号和时码。

## 4. 用工具菜单里的 Agent 制谱

1. 打开「工具 → Agent 设置」。将模型服务提供的地址填入「API URL」，密钥填入掩码显示的「API Key」，再填模型名称并保存。使用 DeepSeek 时，地址可填 `https://api.deepseek.com`，模型可填 `deepseek-flash`。密钥保存于本机用户目录；也可跳过配置，继续手动制谱。[DeepSeek 官方接口说明](https://api-docs.deepseek.com/)
2. 从「工具 → Revelation Co-pilot」打开右侧助手。已有谱面可直接说明要改哪一段，例如「只补 22–24 秒，保留已有音符」。可用时间、标尺拍号或当前选中音符定位。
3. 想按预置提示制谱，点助手底部「一键制谱」，选择 EZ、HD 或 EX。要求可以留空，也可以写「主歌留白，副歌随鼓点展开，保留原有长键」。点「发送给 Agent」后开始请求模型。
4. 在助手中查看拟写入的音符，按需批准或拒绝。助手可参考重音、响度和频段来编排。提交后在目标段落试听，整轮修改可用一次撤销恢复。曲绘或预览图像由「允许发送曲绘、预览和音频图」控制。

## 5. 预览并导出

1. 在卷帘顶部标尺上定位，再点击卷帘工具栏的「播放」。也可打开右上的「预览控制」，选择「从当前拍试玩」「循环预览选区」或「游戏画面」。打开「自动滚屏」可让卷帘跟随播放指针。试玩后点击右上「返回编辑」继续编辑音符。
2. 编辑中用「文件 → 保存谱面」保存，菜单会显示当前保存快捷键。要交付给游戏或分享整份谱面，走**文件 → 导出谱面压缩包**，生成 ZIP。
3. 想分享一段可直接观看的预览，走**文件 → 渲染视频**，生成带音频的 MP4。

## 从原版迁移

在「帮助 → 原版迁移引导」可逐项打开现有控件。习惯原版手势时，可在「编辑 → 编辑器偏好设置 → 快捷键」选择原版方案。原版方案用上档键＋右键拖框、控制键＋左键移动。单独长按右键会打开工具菜单。

「波形」位于偏好设置，歌曲延迟和倍速仍在检查器「音频」。输出设备和启动音效则在偏好设置的「音频」页。也可在[功能与入口说明](功能与入口说明.md)里按功能查找新的位置。

## 草稿、分段 BPM 与续编

导入歌曲并放键后按 Ctrl+S，自动保存也写入当前草稿。回到首页选择「继续上次编辑」，会恢复最后保存的音符及播放头。正式导出 JSON 或 ZIP 时需要曲名、音频、底图和覆盖图。在同一台电脑上重新打开谱面，卷帘会按该谱面和难度的 BPM 缓存恢复变速点、标尺与吸附网格。含 tempoGrid 的旧谱优先读谱内分段。将 JSON 或 ZIP 传给其他电脑时，基础 BPM 随谱分发，分段缓存留在本机。

## 复制音符与选区改谱

在卷帘上选中一组音符，右键选择「复制为 JSON（跨工程）」。把剪贴板文本传到目标电脑，在目标卷帘的轨道和时间处右键选择「粘贴 JSON（跨工程）」。第一颗键的判定对齐点击位置，其余保持相对间距。提示会列出占位和越界的颗数，Ctrl+Z 可撤销整次粘贴。

框选一段卷帘，点「让助手修改此段」。默认勾选「仅新增，保留已有音符」。完成后可查看新增、移动或调整、删除的数量，并从选区起点分别循环试听原谱和草稿。点「接受草稿」提交，Ctrl+Z 可整段撤销。

## 手序与八拍练习

选中音符后从右键菜单打开「手序与引导预览」，可查看前后各两次判定的位置、间隔和仍占手的长键。首次教程或「帮助 → 8 拍练习谱」可重播、重置黄键和遮罩练习。拖动黄键终点后松开会立即回放。切到遮罩练习后，用三个按钮在同一拍比较原画面、压暗背景与圆形揭示。
