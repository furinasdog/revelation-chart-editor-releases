# 更好的制谱器 4.7 功能与入口说明

## 工作区与检查器

上方菜单提供文件、编辑、视图、分析、工具、帮助。左上检查器的「全部页签」可切换键设置、动画设置、事件、预览设置、音频及导入导出。先选中卷帘中的音符，再在检查器调整起止时间、判定点、位置、移动路径与缓动。右上谱面预览显示实际画面，底部卷帘用于按时间和轨道编排音符与事件。

## 节奏、频率与情绪分析

导入歌曲后在「分析」菜单启动当前配置的分析，右上「节奏分析」查看速度和重拍。「频率显示」用于对照频段能量、瞬态与响度，判断鼓点、人声或乐句的变化。「情绪分析」使用 Music2Emo 标示段落情绪，用于安排密度与留白。将结果用作编辑参考可以改变吸附依据，「写入谱面速度」会改变谱面的速度分段。

## 背景遮罩、关键帧与预览

在左侧事件和动画设置中选择背景或遮罩事件，对应时间的关键帧控制位置、透明度及过渡。用背景或遮罩轨选择片段，在预览中检查入场、高潮与退场时刻，注意保持落点可读。卷帘工具栏播放与停止可快速重复比较同一小节。

## 制谱助手、MCP 与参考工程

「工具 → Agent 设置」填写 API 地址、模型和密钥。「工具 → Revelation Co-pilot」打开助手，「一键制谱」用于填写难度与要求。也可直接指定秒数、轨道和编辑范围，核对结果后应用。MCP 设置用于外部客户端连接本机编辑会话，可限制读取媒体和共享文件路径。导入参考谱后可查询段落的音符分布、事件及遮罩设计。脚本入口支持运行 .rpy。

## 导出、反馈与帮助

「文件」可导出独立 JSON、带资源的 ZIP 或渲染预览视频。渲染前在预览中检查背景、音频与判定时间。「帮助」提供功能速查、新手与迁移引导、更新公告和错误包导出。功能速查可搜索术语并直接跳往对应编辑控件。

以 Revelation 原版制谱器 1.9.2 为对照。新版顶部是菜单，左上是检查器，右上是谱面预览和节奏分析，底部整层是钢琴卷帘。画笔和播放控制位于卷帘上沿。

| 功能 | 入口与操作 |

| 自动识别拍点、小节重拍和动态速度 | 「文件 → 导入音频」后选择「自动分析」，也可从「分析 → 按当前设置分析」启动。右上「节奏分析」显示速度曲线。分析结果提供制谱参考，音符可在卷帘中编排或从已有谱面导入。 |

| 功能速查 | 右下「功能速查」或顶部「帮助 → 功能速查」，搜索功能名或操作词，再点「前往此处」。 |
| 两种自动参考模式 | 「检查器 → 参考线量化」新增「自动速度」和「抓取拍点」，可分别按速度曲线和拍点时间吸附。 |

| 拖动数值 | 在检查器的数字输入框上横向拖动。按住 Shift 微调，按住 Ctrl 加快。也可点入输入框直接键入。 |

## 原有操作的改进

- **框选音符**。原版用 Shift+右键拖框。新版可切到「选择」工具，直接左键拖框，按住 Shift 可追加选择。
- **移动预览中的音符**。原版在预览区按住 Ctrl 拖动已选中的音符。新版可直接左键拖动，打开「预览网格」可吸附到网格交点。
- **常用快捷键**。默认键位包括空格播放或暂停、Ctrl+S 保存、Ctrl+Z 撤销。可在偏好设置里恢复默认键位。

## 三种参考模式怎么选

| 模式 | 参考线与吸附 |
| --- | --- |
| **传统量化** | 以手工设置的谱面速度和变速节点为准，支持 `1/4` 等拍内细分。本模式旁的「显示拍点」可叠加金色拍点线。 |
| **自动速度** | 以分析得到的动态速度为准。亮蓝粗线是推算的整拍线，暗蓝细线把每拍分成四格。本模式旁有独立的「显示拍点」复选框。导入音频后确认自动分析会切到此模式。 |
| **抓取拍点** | 金黄色竖线是自动抓取的拍点。开启「时间轴吸附」后可直接对齐拍点时间。 |

切换参考模式只改变卷帘参考线与吸附规则。需要将分析结果写入谱面的速度分段时，使用「分析 → 写入谱面速度」。用于游戏的交付文件可通过「文件 → 导出谱面压缩包」生成。
