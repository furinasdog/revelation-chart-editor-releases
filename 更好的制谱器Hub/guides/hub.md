# 更好的制谱器 Hub

顶部「启动、下载、设置、更多」切换分类，左栏选择该分类中的页面，窗口底部显示正在运行的操作和进度，操作结果从右侧弹出。编辑器及其用户资料分别保存。Hub 关闭后，编辑器仍可独立运行。

## 版本库与首次安装

进入「下载 → 版本库」，点右上「刷新版本」查询发行版本。每张版本卡显示版本号、发行日期、包大小和变更。点「安装」下载选中版本，进度显示当前来源及完成量。GitHub 连接失败时会尝试镜像。点击「启动」后，按钮立即显示启动状态。制谱器窗口打开后，按钮变为「停止」。Hub 一次启动一个编辑器，再次打开 Hub 可继续管理仍在运行的版本。点「停止」会请求编辑器正常关闭，有未保存的谱面时请处理编辑器中的提示。左下「安装目录」可在资源管理器查看所有版本。

## 原位升级与增量包

进入「启动 → 已安装」，在需要升级的版本卡点「更新到 v…」。先保存谱面并退出该版本的编辑器。Hub 优先下载当前版本对应的增量包，在暂存区复用本地文件，逐个验证新文件，再替换原安装目录。桌面上已有的编辑器快捷方式可继续使用。发布方未提供相应增量、基础文件损坏或增量传输失败时，会使用完整发行包。可以在「Hub 设置」选择是否优先使用增量。

「版本库」的「安装」用于并行保留不同版本。「已安装」中的「更新到」用于替换选中的那个版本。安装目录里自行添加的谱面和其他文件会随升级保留。同名文件冲突会显示路径，请移出后重试。Windows 任务管理器强制结束 Hub 后，重新打开可恢复未完成的目录切换。

## 文件校验、修复与删除

「已安装 → 校验文件」在本机逐个读取发行文件，核对长度与 SHA-256。结果会列出缺失或损坏的数量及示例文件名。对于内置清单的版本可离线校验。点「修复」可用对应版本完整发行包恢复原文件。校验、修复时启动按钮暂时禁用。请先关闭要维护的编辑器版本。

点「删除版本」并确认，Hub 将整个版本目录移入 Windows 回收站。该目录里自行放入的文件也会一起移动，可从回收站恢复。编辑器在用户目录下保存的设置、参考库和另存的谱面独立于版本目录。

## 模型管理

「下载 → 模型管理」显示 madmom、Music2Emo 和 HTDemucs 的实际目录及配套文件数。madmom 用于节拍、重拍及起音，Music2Emo 用于情绪分析，HTDemucs 用于分离人声、鼓组、贝斯及其他伴奏。「下载或补齐」检查已有文件并补齐缺项，「校验」只读取本地文件。「打开目录」显示实际路径。「移除模型」会删除这一组已知文件，之后可再次下载。

Music2Emo 使用编辑器配置的模型目录，默认存放在用户资料目录下的 music2emo-models/v1。madmom 依次读取分析选项中保存的模型缓存、环境变量和默认缓存目录。HTDemucs 默认存放于用户资料目录下的 `htdemucs-models/v1`，也可用 `AUTOREVELATION_HTDEMUCS_MODELS` 指定保存权重的目录。提示缺模型时，可在编辑器点击「打开 Hub」，安装后回到提示中点「刷新」。Beat This! 等随发行包安装的组件可从「已安装」页面校验。

## 编辑器配置

从「设置 → 编辑器配置」选择「偏好设置」「Agent」或「MCP」。上方标明当前配置文件的位置。可调整主题、缩放、音频设备、启动音、歌词导入、分析模型目录、FFmpeg 路径和快捷键方案。Agent 页可设置兼容服务地址、模型名和 API Key。MCP 页可设置端口、服务路径及素材和路径共享权限。

修改后一律点「保存配置」。关闭编辑器后保存，下次启动会读取相同文件。API Key 输入框遮蔽内容。Hub 只替换本次修改的字段，保留其他配置。如果同时在另一处保存过，点「刷新」重新载入后再修改。

## 参考工程

从「更多 → 参考工程 → 导入参考谱」选择包含谱面的 ZIP 或 JSON。每份谱面 JSON 最大 8 MiB，可保存 64 个本地工程。Hub 导入音符、事件和背景关键帧等谱面数据。需要单独授权图片或音频时，在编辑器「工具 → 导入参考谱」操作。列表显示曲名、难度、条目数及已有素材包。

点「导出 JSON」可保存一份谱面数据副本。点「删除」会移除参考库内的该工程、素材授权和对应素材副本。内置乐句示例由编辑器提供。谱面的实际游戏导出入口在编辑器「文件」菜单。

## Hub 设置与自动更新

「设置 → Hub 设置」可调整增量优先、自动检查 Hub 更新、版本库公告和界面动画。点「保存设置」立即应用。Windows 的减少动画设置优先。Hub 启动、点击「刷新版本」或连续运行 6 小时时检查发行信息。新版 Hub 下载就绪后，点「重启并更新」立即安装，或退出应用自动安装。升级保留开始菜单和桌面快捷方式选择。

## 公告、使用文档与问题反馈

新公告在窗口中央弹出，确认后可以随时点击侧栏「公告」重看。离线时显示最近缓存的公告，首次离线使用时显示安装包中的公告。发现 Hub 或已安装制谱器有新版时也会弹窗；在 Hub 设置中可手动检查 Hub 更新。「更多 → 使用文档」可以同时搜索 Hub 与制谱器的章节标题和正文，以空格组合关键词，单击章节可展开。文档随安装包提供，可离线查看。点击左下「问题反馈」可查看群内反馈方式，请在制谱师/企划群中 @短夜月 反馈。提交错误时可附上 Hub 和编辑器的版本号、复现操作和错误提示。

## 下载与可选 CUDA 支持

版本包、增量包、madmom、Music2Emo 及 Hub 更新优先从 GitHub 下载。HTDemucs 使用 Hugging Face 上固定版本的模型，并校验 SHA-256。支持 HTTP Range 的文件最多同时使用 8 个连接，空闲连接分担剩余较长的区间。断线重试从当前分段已写入的位置继续，必要时自动切换镜像。仅支持整文件传输的下载源使用单连接。底栏显示传输进度。

在「启动 → 已安装」的编辑器卡片上可选择「添加 CUDA 支持」或「卸载 CUDA 支持」。该版本有签名附加包时才会显示入口。修改前请先退出编辑器。没有附加包时，编辑器使用 CPU 进行 ONNX 推理。视频导出的 NVIDIA 硬件编码由显卡的 NVENC 编码器提供，可单独使用。
